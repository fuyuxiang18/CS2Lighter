# CS2Lighter

用于个人 CS2 demo 复盘的 Windows 桌面软件。指定本地文件夹，自动解析对局，查看个人数据、跨比赛习惯、位置热力图和回合证据。

当前版本 **0.7.0**，支持 Windows 10/11 x64。

## 下载与使用

从 [Releases](https://github.com/fuyuxiang18/CS2Lighter/releases/latest) 下载安装包。软件默认简体中文，也可切换 English。

1. 在设置中添加存放 demo 的文件夹，可以添加多个并递归扫描。
2. 在完美等平台下载并解压 demo 到这些文件夹。CS2Lighter 不下载对局，只读取完整的 CS2 `.dem` 文件。
3. 导入面板显示总数、完成数和每个正在处理的文件，可暂停、继续、取消解析或移出待处理项。已有比赛在后台导入期间仍可浏览；数据库正在保存的单场会先保存完成再暂停。失败或未下载完整的文件会单独提示。
4. 输入录制时使用的准确昵称。找到账号后按 SteamID 绑定，后续同账号更名仍可归集；同名多个账号需自行确认。
5. “数据总览”集中展示个人战绩与值得复盘的场景；按输出与对枪、团队与道具、残局与经济、比赛与趋势、趣味记录逐项查看。每个比例展示次数和分母，重点结论可展开对应回合。
6. “我的风格”展示真实行为比例；“练习与进步”按相同地图、阵营、来源、模式及游戏版本比较自己。练习之后只统计发生时间晚于开始时间的比赛，导入旧录像不会被算作练习成果。
7. “地图习惯”中点击有数据的区域回看例子。“比赛记录”提供逐场入口，展开详细统计可查看完整战绩、道具、经济、武器和趋势。
8. 在对枪或回合列表勾选事件，加入左侧“录像队列”。在队列中查看来源、回合、特点和视角，选择需要的片段统一录制；一次最多 20 个事件，跨 demo 共用一次 CS2 启动，按 demo 依次完成。视频编排本人和已核实对手的视角，并在死亡前截止。队列会保存，可移除、暂停后续任务或取消当前任务，完成的视频随时播放。
9. 在“设置 → AI 点评”配置云端 OpenAI 兼容 API 或本机 Ollama。个人风格、每场比赛和已生成视频中的单个事件均可主动生成点评。视频点评先在本机提取并预览关键帧，确认点击生成才把这些图片与相关事实发给所选模型；需要支持图像的模型。

统计点评支持枪法、突破、补枪、道具、残局五维主观评分与 2–5 字玩法风格标签。枪法根据战绩和武器表现估计；没有残局等相关情境时显示数据不足。在“设置 → AI 点评”可修改输出 token 上限，默认 240,000，支持 1–1,000,000 的整数，个人、单场和视频点评共用。模型和服务仍有各自支持的上限；此数字不是固定消耗量。修改设置保留已有点评，复用既有 demo 数据。

0.7 增加回合输出分布、首杀后的胜负、生存与补枪、闪光效率、半场表现、同条件近期趋势和 15 类趣味记录。总结从具体次数出发，给出可以回到录像中核对的复盘动作。高级分析使用标准 5v5 数据；历史 Rating、RWS 和各项分母可展开查看。详细口径见 [0.7 数据分析](docs/0.7.0-data-analysis.md)。

个人指标包含爆头率、K/D、ADR、KAST、Rating 1.0 历史公式、RWS 本地计算、首杀／首死、补枪、残局、多杀、闪光和道具伤害等。计算口径、覆盖范围及调研来源见 [指标说明](docs/METRICS.md)。不提供封禁查询、置顶玩家或高手学习工作区。

片段录制需要 Steam、CS2、HLAE 与 FFmpeg，会打开游戏窗口。队列存于用户数据目录 `recording-queue`，旧单片段和编排视频分别存于 `review-clips`、`review-batches`。视频 AI 点评按事件提取关键帧；预览后点击生成，才将图片发送到配置的模型。整段视频留在本机。详细说明见 [视频 AI 点评](docs/VIDEO-AI-REVIEW.md) 和 [AI 统计复盘](docs/AI-REPORTS.md)。

## 更新与数据

在“设置 → 关于 → 应用更新”检查、下载并重启更新。更新来自本项目的 GitHub Releases，无需登录 GitHub。

从 0.1.0 需要手动安装新版一次，以获得应用内更新功能；0.2.0 及以后可在应用内升级。**安装器应用标识、可执行文件名和数据路径保留兼容**；内部文件名仍是 `cs2-parser.exe`，Windows 数据仍在 `%LOCALAPPDATA%\CS2Parser`。原始 demo 保留在你选择的目录，绑定和旧笔记保存在同一用户数据目录的 `ui` 子目录。

每个 demo 对应一个 `demodata/<checksum>.json` 数据文件，优先放在安装目录内，例如 `cs2-parser\demodata`。目录不可写时使用用户数据目录下的 `demodata`，界面显示实际位置。0.7 沿用缓存格式 3，新面板直接聚合旧缓存；缺失缓存从数据库回填。普通添加已入库的 demo 会跳过，只有明确勾选重新分析才运行原始解析器。详情见 [数据兼容性](docs/DATA-COMPATIBILITY.md)。

数据库保存比赛事件和用于 2D 回放的逐时刻轨迹，体积可能大于紧凑的原始 demo。0.6 停止保存无分析价值的鸡轨迹，并修复重复导入与统计计数。设置中的数据库页显示实际物理目录和主要占用；旧版已经产生的文件不会因更新自动压缩。迁移必须正常停库后复制完整数据库、校验并验证，不能直接删除 `postgres/data/base` 中的数字文件。

更新不会删除数据库、绑定或缓存。手动备份时先退出软件并等后台任务结束，再备份完整用户数据目录和实际 `demodata` 目录；原始 demo 单独备份。

## 本地开发

安装 [Vite+](https://viteplus.dev/)，使用仓库固定的 Node 和依赖版本：

```sh
vp install
vp run dev
vp run test
vp check --no-fmt
vp run deadcode
vp run i18n:extract
vp run build
vp run package --win --publish never
```

Windows 构建需要 Visual Studio C++ Build Tools 与 Python（Electron 原生依赖）。安装脚本准备解析器和内嵌 PostgreSQL；发行版用户无需单独安装它们。

中英文翻译随源代码提交，离线构建不依赖 Crowdin。研发测试可设置绝对路径 `CS2_PARSER_DATA_DIR` 隔离测试资料；不应把个人 demo、数据库、账号绑定或密钥提交到仓库。

版本和发布流程见 [发布说明](docs/RELEASING.md)。
