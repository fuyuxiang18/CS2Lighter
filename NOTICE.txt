This fork adds explicit folder auto-import, account matching, cross-match habits,
and a player learning workspace. It uses an independent application/data identity
and downloads application updates only from its own GitHub Releases feed.
Demo files are only read from folders explicitly configured by the user.

Bundled components retain their own licenses, including Electron, PostgreSQL,
cs-demo-analyzer, demoinfocs-golang, and CS Demo Manager's runtime components.
