# CS2Lighter 0.5.0

本版将复盘中的数字、事件、真实第一人称画面与可核查的 AI 建议连接起来。现有账号绑定、逐 demo 数据缓存、中文默认、只读取指定文件夹和更新保留数据的行为不变。

## 使用流程

1. 在「复盘工作台 → 对枪与第一视角」查看交火列表。首杀成功率卡可直接筛选本人参与的首杀、首死；也可分别查看击杀、死亡、伤害遭遇。
2. 选择事件后可以直接在 CS2 定位本人视角，或按需录制片段。定位观看需要本机 CS2、Steam 和 HLAE；保存视频另需 FFmpeg。缺少依赖时提供设置入口。录制会打开游戏窗口，游戏运行中不自动关闭它来录制。
3. 片段成功保存后在页面内播放，后续打开读取本地 MP4，不重复录制。2D 回合入口仍可查看全局位置关系。此画面是 demo 重放，不是玩家当时屏幕的原始录像。
4. 在「设置 → AI 点评」选择云端 OpenAI 兼容 API 或本机 Ollama，配置地址与模型。云端密钥由操作系统加密保存；本地无密钥模型无需云端账号。
5. 「我的风格」可生成当前筛选下最近比赛的风格与建议；「比赛记录」每场有独立的 AI 点评入口。点击生成才调用模型，生成后保存，重新打开读缓存。

## 事件口径

对枪列表实际是可观测战斗事件索引：包含敌方击杀、本人被敌方击杀以及双方伤害遭遇。相同对手相同回合的伤害按五秒间隔分组，连续组最长三十秒；结束附近有对应击杀时合并到击杀/死亡记录。未造成伤害的交火、双方只观察未开枪的接触无法可靠识别，不冒充全部对枪。道具伤害也会出现，并显示武器名称。

首杀是回合胜负确定前的第一个有效敌方击杀，本人首杀成功率 = 本人首杀 /（本人首杀 + 本人首死）。非本人参与的首杀不计入分母。交火列表可包含回合胜负确定后、正式结束前的战斗，它们不算首杀。保留赛内 tickrate，不假设 64 tick。

每页二十条，地图、来源、阵营与账号遵循页面筛选。后端从已解析数据库读取事件，浏览不重新解析原始 demo。

## 视频与 AI 的边界

- 录像按需生成，不会录制整库或自动下载比赛。输出存个人数据目录 `review-clips`，不写入原始 demo 目录。
- 录制使用 demo 副本、独立临时游戏配置与 HLAE 自身的命令调度，不安装旧的回放控制插件、不改写游戏 `gameinfo.gi`。检测到其他回放遗留的插件或配置备份时先提示解决冲突。片段最大四十五秒，默认二十秒。真实录制和兼容性仍取决于游戏、地图与 HLAE 版本。中断后展示可重试状态。
- AI 输入为合计数据与抽样回合，**本版 AI 不看视频**。不给枪法、预瞄、反应或沟通虚构结论。证据引用校验不等于文字判断一定正确，需要结合回放核查。
- 评分是注明样本门槛的模型主观评估，默认收起，不能用作段位或平台评分。没有足够证据时显示未评。
- AI 报告单独缓存于个人数据目录 `ai-reports`，配置位于 `ai-config.json`。缓存按账号、事实、筛选、服务端点、模型和提示版本隔离。详细协议和隐私边界见 [AI-REPORTS.md](AI-REPORTS.md)。

本版不需要清除已有 `demodata`，也不改变安装器的数据保留策略或旧身份绑定键。
