# CS2Lighter 0.2.0

- 软件正式更名为 CS2Lighter。
- 默认简体中文，语言选项仅简体中文和 English；翻译随安装包提供。
- 移除对局下载功能，仅自动读取用户指定的多个文件夹。
- 新增导入进度、失败明细和重试；解析入库期间暂停数据浏览，完成后自动开放。
- 移除顶栏前进、后退按钮，改善较小窗口的页面布局。
- 新增应用内更新检查、下载进度和“重启并更新”，升级保留本地数据。

从 0.1.0 升级：安装本版本一次即可；后续在“设置 → 关于 → 应用更新”中更新。
内部数据目录与应用标识保持兼容，不需要重新绑定账号或重新解析已有比赛。

支持 Windows 10/11 x64。基于 CS Demo Manager 开源项目（MIT），保留上游及第三方许可。
