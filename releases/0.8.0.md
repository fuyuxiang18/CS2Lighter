# CS2Lighter 0.8.0

这次更新把重点放在数据复用、存储体积和复盘效率。

- **批量死亡分析**：在死亡列表勾选多条，或选中整页，统一分析。同场的多个时间窗口合并读取，按窗口保存结果；支持暂停、重试和重启后继续，已保存的证据直接复用。
- **即时 2D 复盘**：死亡详情内直接播放交火前后的已保存位置，支持拖动、循环、半速/倍速、跳到死亡时刻和事件定位。无需启动 CS2。可以继续打开完整回合或查看真实 POV。
- **更紧凑的位置存储**：新导入的玩家位置按玩家、回合分块压缩，保留坐标、朝向、姿态、装备等字段。旧位置数据直接兼容，不强制迁移或重解析。
- **录像流水线**：同场片段优先向前录制，减少反复跳回开头；录制与编码可以衔接运行，并限制积压。最终视频仍按本人、对手等原有编排顺序组合。已完成成片后清理本次录制的原始媒体。
- **分层缓存版本**：统计与热力图计算分别管理版本，计算规则变化只重建受影响的摘要。应用版本号不作为清空数据的依据。
- 修复位置回放的蹲姿字段映射，增强损坏数据检查、取消和批量进度恢复。

真实 demo 对照：同一场 1,822,880 条位置记录，新位置表及索引约 33.8 MB，旧格式约 440.5 MB；抽取窗口、10 名玩家的习惯汇总和 163 次死亡记录对照一致。该结果针对这场的位置数据，实际节省因 demo 而异。

升级保留比赛、账号绑定、设置、笔记、demodata 和视频。旧数据库不会在升级时自动压缩，因此已有磁盘占用不会立即下降。历史地图精确匹配与无法验证的压枪归因继续保持原有证据要求。
