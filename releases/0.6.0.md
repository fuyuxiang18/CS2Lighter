# CS2Lighter 0.6.0

- 修复同一路径重复计数及普通添加已保存比赛时重复解析。沿用缓存格式 3，升级复用 0.4/0.5 有效缓存。
- 未保存完整的比赛单独标记，生成画像时跳过；意外退出后提示明确重试，防止把半场数据保存成正式缓存。取消状态覆盖跨目录的同一 demo 副本。
- 导入可暂停、继续、取消解析/缓存生成和移除排队文件；等待期间可以浏览已完成比赛，数据库正在保存的一场会先安全保存。
- 改进轨迹聚合和缓存共享，减少整库反复刷新；停止保存没有分析价值的鸡轨迹。
- 支持多选最多 20 个事件批量录制，同一 demo 共用一次游戏启动。按本人和已核实对手视角编排，死亡前截止，生成合集和可跳转章节，缓存直接复用。
- 增加可选的视频 AI 点评：先预览关键帧，主动生成时发送给云端或本地视觉模型；结论引用具体画面，区分本人可知信息与事后信息，并给出练习动作。
- 数据库页显示实际物理目录与主要空间占用，移除容易误删玩家轨迹的旧清理入口。

首次录像仍需要 CS2、Steam、HLAE 与 FFmpeg 实际渲染。视觉点评使用抽样帧，不能测量精确反应时间或连续压枪；图片中可能含昵称、头像、聊天，整段视频留在本机。没有实现自动自由上帝视角。

更新保留比赛、账号绑定、笔记和缓存，不会自动重解析整库。旧版已经占用的数据库空间需要单独维护回收，不会在安装时自动压缩。
