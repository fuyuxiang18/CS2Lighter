# CS2Lighter 0.7.4

- **R1 首枪未急停**：支持读取射击事件或独立弹道伤害事件中明确记录的移动精度损失，核对射手、武器、目标和射击时钟；证据表展示直接分量及来源。未录制这些字段的 demo 不会用默认值补齐。
- **R8 杀后暴露**：新增“击杀后离开掩体，进入新枪线并受伤”的判定。逐帧检查原掩体对当时所有存活敌人是否仍有遮挡，展示击杀、离开掩体和受击位置，并给出针对下一次交火的建议。
- **R4 动作证据**：提取 demo 内的动画资源表、当前动作指令和姿态任务链，保存紧凑摘要，在死亡复盘中展示解码进展。当前尚未重建射击时刻的最终人体姿态，因此不把动作指令或准星上扬直接判成压枪失误。
- **历史复盘兼容**：游戏更新后可继续读取同一比赛的已保存证据。新增采集仅在手动重新提取时执行，不自动重解析所有 demo。

本次只读复核的四份 demo 共 10,210 次射击，均未录制额外精度分量。R2/R3 在这些样本中的动态精度归因缺口仍存在，未通过放宽阈值增加结论。R8 的真实样本因本机地图版本不匹配，没有生成正例；判定边界通过独立合成几何测试验证。

详细数据、实际测试与后续缺口：[精度](https://github.com/fuyuxiang18/CS2Lighter/blob/main/docs/research/precision-data.md) · [动作与压枪](https://github.com/fuyuxiang18/CS2Lighter/blob/main/docs/research/aim-data.md) · [杀后掩体](https://github.com/fuyuxiang18/CS2Lighter/blob/main/docs/research/retreat-data.md)。
