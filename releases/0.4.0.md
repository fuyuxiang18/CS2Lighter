# CS2Lighter 0.4.0

本版把“看更多统计”改为“找到值得回看的场景，带着一个具体动作打下一场”。

- 全新石墨蓝／青绿界面，文字侧栏分为复盘工作台、地图习惯、比赛记录；高级工具折叠，深浅主题和小窗口适配保留。
- 复盘重点展示首死、首杀后输局、未被补枪、友军致盲、残局失利的实际比例、明确分母和对应回合。事件是待复核线索，不自动判错。
- 回看后可标记已复盘或战术安排，选一个具体动作作为当前练习重点；回放有返回复盘入口。
- 用首对枪参与、补枪、道具使用、生存、残局参与描述风格，不提供未经验证的能力分或人格标签。
- 新增按地图、阵营、来源、模式、游戏版本分组的本人前后比较。训练统计以实际比赛时间分界，旧录像不会被算成新进步；样本不足时不展示差值结论。
- 热力图所有有数据的区域均可点击和键盘选择，范围和覆盖率就近说明；完整战绩放在比赛记录的详细统计中。
- 筛选、复盘状态与练习重点本地保存；更换账号可取消且不会提前清空旧绑定。
- 继续使用逐 demo 数据文件；缓存格式升级后从已有数据库补充事件时间，不重新读取原始 demo。普通缓存读取不再重复遮挡整个界面。

升级保留原有数据库、demo 缓存、账号绑定及用户设置。安装标识和数据路径保持兼容。
