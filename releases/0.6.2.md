# CS2Lighter 0.6.2

- “设置 → AI 点评”新增可保存的输出 token 上限，默认 240,000，可输入 1–1,000,000 的整数，支持恢复默认值。
- 个人、单场及视频点评统一使用保存的上限，重新启动仍然保留；原有 API 密钥无需重新填写。
- 根据上限调整响应容量及请求等待时间，最长等待三十分钟，避免较长思考响应仍被旧固定限制提前终止。最终点评继续保持简练，并校验结构与引用。
- 生成状态显示实际配置的上限；错误提示引导检查设置及模型支持范围。

上限不是固定消耗量，也不能突破模型或服务自身的限制；不支持较高上限的模型可在设置中调低。升级保留原有 demo 数据和已保存点评，无需重新解析或自动重新生成。
