# CS2Lighter 0.7.3

## 死亡详情：枪线与连射轨迹

- 补全 0.7.2 的进阶死亡证据。在“我的复盘 → 逐次死亡”展开一条记录，查看死亡前的多人枪线、对手朝向与逐发射击方向。
- 用本机 CS2 地图的三维几何检查环境遮挡，识别持续的多人枪线窗口，显示人数、持续时间、夹角和回看入口。敌人的朝向单独展示。
- 逐发方向图可以按连射分段切换，标出连续上扬、下压和横向摆动，给出对应的复盘与练习动作。结论描述实际射击方向，不将转移目标直接判成压枪错误。
- 全程使用 demo 事件和确定性规则，不调用 AI，不启动游戏，也不下载 demo。

## 提取、缓存与兼容

- 只在首次展开该次死亡时提取最多 7 秒的高频证据，显示进度，支持暂停、重试和手动重新提取。再次打开直接读取缓存。
- 进阶结果按 demo 压缩保存到 `demodata/death-evidence`；地图与动态模型缓存共用，避免重复准备。不新增整场高频数据库表。
- 原 demo 移走后仍能查看已保存的证据；删除比赛会清理对应缓存，避免后台任务写回已删除的数据。
- 原有比赛、账号、设置、笔记、录像队列与逐场统计缓存保持兼容，升级不会触发全库重新解析。
- 地图枪线要求 demo 与本机地图版本匹配。旧地图或尚未取得完整遮挡证据的片段保留基础复盘及射击轨迹，缺少的部分在“证据覆盖”中显示。当前已验证的地图版本对应 demo patch 14190。

判定范围与逐项阈值见仓库 `docs/0.7.3-death-evidence.md`。本版本继续扩展已经发布的 0.7.2，不覆盖原发布包。
