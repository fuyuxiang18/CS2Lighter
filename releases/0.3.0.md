# CS2Lighter 0.3.0

本版聚焦个人 demo 分析，减少无关入口，并让跨比赛统计可重复快速读取。

- 移除捐助、上游更新日志及相关推广内容；保留鸣谢与开源许可。
- 移除封禁查询、VAC 等相关界面、筛选、通知和后台检查。
- 移除“向高手学习”和“置顶的玩家”入口及功能，保留已有用户资料。
- 导入和数据准备显示真实 demo 数量进度，覆盖解析、入库、逐场数据文件生成；完成前暂停数据浏览。
- 每个 demo 生成一个 `demodata/<checksum>.json` 文件。已有对局首次升级时从数据库回填，后续直接加载缓存。
- 个人分析新增爆头率、Rating 1.0 历史公式、RWS 本地计算、ADR、KAST、胜率、首杀、补枪、残局、多杀、武器、道具、经济、地图／阵营分组及逐场趋势。
- 所有比率按累计原始事件计算；缺失数据显示为空，并说明计算覆盖范围。
- 缓存目录优先位于安装目录下，不可写时显示实际回退路径；安装更新保留缓存、数据库和账号绑定。

Rating 采用公开历史公式，RWS 采用公开的 FACEIT 2025 伤害与炸弹目标规则进行本地计算，不等于平台认证评分或 HLTV 2.x／3.0。详见仓库的 `docs/METRICS.md`。
