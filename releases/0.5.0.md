# CS2Lighter 0.5.0

- 新增「对枪与第一视角」：分页浏览击杀、对枪死亡、首杀/首死和伤害遭遇。点击首杀成功率即可查看对应事件。
- 复盘候选与 AI 证据可打开真实第一人称回放；按需通过本机 CS2 录制并保存 MP4，在解析器内播放。已生成片段不重复录制，支持进度状态、取消、失败重试及依赖设置入口。
- 新增个人风格 AI 总结和单场 AI 点评，提供与回合证据关联的建议。支持云端 OpenAI 兼容 API 与本机 Ollama，可在设置中自行选择。
- AI 仅在点击生成时调用，报告保存在本机。模型输入为去除账号、昵称和文件路径的统计与抽样事件，本版不会把视频发给 AI；没有画面依据时不评枪法、预瞄和反应。
- API 密钥使用操作系统加密，不进入报告与日志；切换服务地址会移除旧密钥。

录制需要 Windows、CS2、Steam、HLAE 和 FFmpeg，并会打开游戏窗口。demo 回放不是原始玩家屏幕录像，旧 demo 能否回放取决于游戏版本。云端 API 可能收费，模型需用户自行配置。未造成伤害的交火不在事件索引中。

保持现有安装标识、用户数据目录、账号绑定和逐 demo 缓存，无需重新导入已有比赛。
